# O2Jam documentation

O2Jam is an audio library for rhythm games, written in C-style C++ on top of BASS. It plays streams (songs) and samples (sound effects), and can change a song's speed with or without changing its pitch.

The docs come in two parts:

- **Concepts** explain the ideas behind the library. Read these first. The reference pages assume them.
- **Reference** has one page per function or struct, all with the same layout: what it does, its declaration, parameters, return value, remarks, an example, and related pages.
